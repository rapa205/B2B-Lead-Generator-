# 📊 Automated B2B Lead Generator & Scraper

A lightweight Python-based automation script designed to aggregate high-value B2B leads from target directories and instantly export structured data for outreach campaigns.

## 🚀 Features
- **Automated Scraping:** Simulates target directory aggregation and filters high-value contacts.
- **Instant CSV Export:** Compiles clean, structured datasets ready to open in Microsoft Excel or Google Sheets.
- **Outreach-Ready:** Formats leads with names, niches, emails, and statuses for immediate sales outreach.
- **100% Open Source:** Clean and extensible codebase.
